Kebijakan Privasi Countdown Keeper

Terakhir diperbarui: September 2026

Countdown Keeper (“aplikasi”) adalah aplikasi seluler yang diterbitkan oleh Thiban Tech Solutions. Kebijakan ini menjelaskan cara aplikasi menangani informasi Anda. Kami menghormati privasi Anda: aplikasi tidak memerlukan proses masuk (login), dan kami tidak mengumpulkan, menjual, atau membagikan informasi pribadi Anda.

Informasi yang ditangani aplikasi

Aplikasi menyimpan konten yang Anda buat: judul acara, tanggal dan waktu, catatan, warna, emoji atau foto opsional yang Anda lampirkan, serta pengaturan aplikasi Anda. Informasi ini disimpan di perangkat Anda dan hanya digunakan untuk menampilkan penghitung dan pengingat Anda.

Izin perangkat

  • Notifikasi — hanya digunakan jika Anda mengaktifkan pengingat, untuk memberi tahu Anda sebelum suatu acara.
  • Kamera — opsional, agar Anda dapat mengambil foto untuk dilampirkan pada acara.
  • Foto — opsional, agar Anda dapat memilih foto untuk acara atau menyimpan gambar acara ke galeri Anda.
  • Biometrik / Face ID — opsional, hanya untuk membuka aplikasi jika Anda mengaktifkan kunci aplikasi.
  • Berjalan setelah mulai ulang (Android) — agar pengingat terjadwal tetap berlaku setelah perangkat dinyalakan ulang.

Setiap izin hanya diminta saat Anda menggunakan fitur terkait.

Penyimpanan data

Semua acara dan pengaturan Anda disimpan secara lokal di perangkat Anda. Aplikasi dapat mengekspor acara Anda ke file JSON dan mengimpornya kembali; Anda yang menentukan di mana file tersebut disimpan dan dengan siapa, jika ada, Anda membagikannya.

Berbagi data

Kami tidak menjual atau membagikan data Anda. Aplikasi tidak memiliki akun pengguna dan tidak memiliki server Countdown Keeper; apa pun yang Anda ketik tidak dikirimkan kepada kami.

Layanan pihak ketiga

Aplikasi tidak menggunakan layanan analitik, iklan, atau pelaporan kerusakan (crash). Satu-satunya permintaan jaringan yang mungkin dilakukan aplikasi adalah ke Google Fonts untuk mengunduh jenis huruf tampilan saat pertama kali dibutuhkan; seperti permintaan web lainnya, permintaan ini mencakup alamat IP perangkat Anda, tetapi tidak ada data pribadi atau konten aplikasi yang dikirimkan. Selain itu, aplikasi berfungsi sepenuhnya secara offline.

Retensi data

Data Anda tetap berada di perangkat Anda sampai Anda menghapusnya. Menghapus acara akan memindahkannya ke tempat sampah, dan acara tersebut akan dihapus secara permanen dari sana di kemudian hari. Mencopot pemasangan aplikasi akan menghapus semua data lokalnya.

Privasi anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak dengan sengaja mengumpulkan informasi dari anak-anak.

Keamanan

Data Anda dilindungi oleh sistem keamanan perangkat Anda sendiri dan sandbox aplikasi. Anda dapat menambahkan lapisan perlindungan ekstra dengan kunci aplikasi biometrik opsional.

Pilihan Anda

Anda mengendalikan izin aplikasi melalui pengaturan perangkat Anda, dan Anda dapat mengekspor atau menghapus data Anda kapan saja dari dalam aplikasi.

Perubahan atas kebijakan ini

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Setiap perubahan akan dipublikasikan di halaman ini dengan tanggal baru.
