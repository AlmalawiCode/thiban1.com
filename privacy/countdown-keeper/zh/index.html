Countdown Keeper 隐私政策

最后更新：2026年9月

Countdown Keeper（“本应用”）是由 Thiban Tech Solutions 发布的移动应用。本政策说明本应用如何处理您的信息。我们尊重您的隐私：本应用无需登录，我们不会收集、出售或共享您的个人信息。

本应用处理的信息

本应用会存储您创建的内容：事件标题、日期和时间、备注、颜色、表情符号或您选择附加的照片，以及您的应用设置。这些信息存储在您的设备上，仅用于显示您的计时器和提醒。

设备权限

  • 通知 — 仅在您开启提醒时使用，用于在事件发生前提醒您。
  • 相机 — 可选，以便您拍摄照片并附加到事件。
  • 照片 — 可选，以便您为事件选择照片，或将事件图片保存到相册。
  • 生物识别 / Face ID — 可选，仅在您开启应用锁时用于解锁本应用。
  • 重启后运行（Android） — 使已安排的提醒在设备重启后仍然有效。

每项权限仅在您使用相关功能时才会请求。

数据存储

您的所有事件和设置均存储在您的设备本地。本应用可将您的事件导出为 JSON 文件并重新导入；该文件的保存位置以及是否与他人共享、与谁共享，均由您决定。

数据共享

我们不会出售或共享您的数据。本应用没有用户账户，也没有 Countdown Keeper 服务器；您输入的任何内容都不会发送给我们。

第三方服务

本应用不使用任何分析、广告或崩溃报告服务。本应用可能发出的唯一网络请求，是在首次需要时向 Google Fonts 下载显示字体；与任何网络请求一样，该请求会包含您设备的 IP 地址，但不会发送任何个人数据或应用内容。除此之外，本应用可完全离线使用。

数据保留

您的数据将保留在您的设备上，直至您将其删除。删除的事件会被移至回收站，之后将从回收站中永久删除。卸载本应用将删除其所有本地数据。

儿童隐私

本应用并非面向儿童，也不会在知情的情况下收集儿童的信息。

安全

您的数据受到设备自身安全机制和应用沙盒的保护。您还可以启用可选的生物识别应用锁，增加一层额外保护。

您的选择

您可以在设备设置中管理本应用的权限，并可随时在应用内导出或删除您的数据。

本政策的变更

我们可能会不时更新本政策。任何变更都将在本页面发布，并注明新的日期。
