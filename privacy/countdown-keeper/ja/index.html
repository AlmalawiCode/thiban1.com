Countdown Keeper プライバシーポリシー

最終更新日:2026年9月

Countdown Keeper(以下「本アプリ」)は、Thiban Tech Solutions が提供するモバイルアプリです。本ポリシーでは、本アプリがお客様の情報をどのように取り扱うかを説明します。当社はお客様のプライバシーを尊重します。本アプリはログインを必要とせず、当社がお客様の個人情報を収集・販売・共有することはありません。

本アプリが取り扱う情報

本アプリは、お客様が作成したコンテンツ(イベントのタイトル、日付と時刻、メモ、色、添付した絵文字または任意の写真)およびアプリの設定を保存します。これらの情報はお客様のデバイスに保存され、カウンターとリマインダーの表示にのみ使用されます。

デバイスの権限

  • 通知 — リマインダーを有効にした場合にのみ、イベントの前にお知らせするために使用します。
  • カメラ — 任意。イベントに添付する写真を撮影するために使用します。
  • 写真 — 任意。イベント用の写真を選択したり、イベントの画像をギャラリーに保存したりするために使用します。
  • 生体認証 / Face ID — 任意。アプリロックを有効にした場合に、アプリのロック解除にのみ使用します。
  • 再起動後の実行(Android) — デバイスの再起動後も、予定されたリマインダーを維持するために使用します。

各権限は、関連する機能をご利用になる際にのみ要求されます。

データの保存

お客様のイベントと設定はすべて、デバイス内にローカルに保存されます。本アプリはイベントを JSON ファイルにエクスポートし、再度インポートすることができます。そのファイルの保存先と、共有する場合の共有相手はお客様ご自身が選択します。

データの共有

当社はお客様のデータを販売・共有しません。本アプリにはユーザーアカウントも Countdown Keeper のサーバーもなく、お客様が入力した内容が当社に送信されることはありません。

第三者サービス

本アプリは、分析、広告、クラッシュレポートのサービスを使用しません。本アプリが行う可能性のある唯一のネットワーク通信は、表示用フォントが初めて必要になった際にそれをダウンロードするための Google Fonts へのリクエストです。一般的なウェブリクエストと同様に、この通信にはデバイスの IP アドレスが含まれますが、個人データやアプリのコンテンツが送信されることはありません。それ以外の点では、本アプリは完全にオフラインで動作します。

データの保持

お客様のデータは、お客様が削除するまでデバイス上に保持されます。イベントを削除するとごみ箱に移動し、後でごみ箱から完全に削除されます。本アプリをアンインストールすると、本アプリのローカルデータはすべて削除されます。

子どものプライバシー

本アプリは子どもを対象としたものではなく、子どもから故意に情報を収集することはありません。

セキュリティ

お客様のデータは、デバイス自体のセキュリティ機能とアプリのサンドボックスによって保護されています。任意の生体認証によるアプリロックを使用して、保護をさらに強化することができます。

お客様の選択

本アプリの権限はデバイスの設定から管理でき、データはいつでも本アプリ内からエクスポートまたは削除できます。

本プライバシーポリシーの変更

当社は本ポリシーを随時更新することがあります。変更内容は、新しい日付とともに本ページに掲載します。
