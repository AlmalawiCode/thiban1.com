Countdown Keeper کی رازداری پالیسی

آخری تازہ کاری: ستمبر 2026

Countdown Keeper (”ایپ“) ایک موبائل ایپ ہے جسے Thiban Tech Solutions نے شائع کیا ہے۔ یہ پالیسی وضاحت کرتی ہے کہ ایپ آپ کی معلومات کو کس طرح استعمال کرتی ہے۔ ہم آپ کی رازداری کا احترام کرتے ہیں: ایپ میں سائن اِن کی ضرورت نہیں، اور ہم آپ کی ذاتی معلومات نہ جمع کرتے ہیں، نہ فروخت کرتے ہیں اور نہ کسی کے ساتھ شیئر کرتے ہیں۔

ایپ جن معلومات کو استعمال کرتی ہے

ایپ وہ مواد محفوظ کرتی ہے جو آپ خود بناتے ہیں: ایونٹس کے عنوانات، تاریخیں اور اوقات، نوٹس، رنگ، کوئی ایموجی یا اختیاری تصویر جو آپ منسلک کریں، اور آپ کی ایپ سیٹنگز۔ یہ معلومات آپ کے آلے پر محفوظ رہتی ہیں اور صرف آپ کے کاؤنٹرز اور یاد دہانیاں دکھانے کے لیے استعمال ہوتی ہیں۔

آلے کی اجازتیں

  • اطلاعات — صرف اس صورت میں استعمال ہوتی ہیں جب آپ یاد دہانیاں فعال کریں، تاکہ کسی ایونٹ سے پہلے آپ کو مطلع کیا جا سکے۔
  • کیمرا — اختیاری، تاکہ آپ کسی ایونٹ کے ساتھ منسلک کرنے کے لیے تصویر کھینچ سکیں۔
  • تصاویر — اختیاری، تاکہ آپ کسی ایونٹ کے لیے تصویر منتخب کر سکیں یا ایونٹ کی تصویر اپنی گیلری میں محفوظ کر سکیں۔
  • بایومیٹرک / Face ID — اختیاری، صرف ایپ کو اَن لاک کرنے کے لیے، اگر آپ ایپ لاک آن کریں۔
  • دوبارہ شروع ہونے کے بعد چلنا (Android) — تاکہ طے شدہ یاد دہانیاں آلہ دوبارہ شروع ہونے کے بعد بھی برقرار رہیں۔

ہر اجازت صرف اسی وقت طلب کی جاتی ہے جب آپ متعلقہ فیچر استعمال کرتے ہیں۔

ڈیٹا کا ذخیرہ

آپ کے تمام ایونٹس اور سیٹنگز مقامی طور پر آپ کے آلے پر محفوظ ہوتی ہیں۔ ایپ آپ کے ایونٹس کو JSON فائل میں ایکسپورٹ کر سکتی ہے اور انہیں واپس امپورٹ کر سکتی ہے؛ یہ فائل کہاں محفوظ ہو اور اسے کس کے ساتھ شیئر کیا جائے، اگر کسی کے ساتھ کیا جائے، اس کا انتخاب آپ خود کرتے ہیں۔

ڈیٹا کی شیئرنگ

ہم آپ کا ڈیٹا نہ فروخت کرتے ہیں اور نہ شیئر کرتے ہیں۔ ایپ میں کوئی صارف اکاؤنٹ نہیں اور نہ ہی Countdown Keeper کا کوئی سرور ہے؛ آپ جو کچھ بھی ٹائپ کرتے ہیں وہ ہمیں نہیں بھیجا جاتا۔

فریقِ ثالث کی خدمات

ایپ تجزیات، اشتہارات یا کریش رپورٹنگ کی کوئی سروس استعمال نہیں کرتی۔ ایپ واحد نیٹ ورک درخواست صرف Google Fonts کو کر سکتی ہے، تاکہ پہلی بار ضرورت پڑنے پر ڈسپلے فونٹ ڈاؤن لوڈ کیا جا سکے؛ کسی بھی ویب درخواست کی طرح اس میں آپ کے آلے کا IP ایڈریس شامل ہوتا ہے، لیکن کوئی ذاتی ڈیٹا یا ایپ کا مواد نہیں بھیجا جاتا۔ اس کے علاوہ ایپ مکمل طور پر آف لائن کام کرتی ہے۔

ڈیٹا کو برقرار رکھنا

آپ کا ڈیٹا اس وقت تک آپ کے آلے پر رہتا ہے جب تک آپ اسے حذف نہ کریں۔ کسی ایونٹ کو حذف کرنے سے وہ ری سائیکل بِن میں چلا جاتا ہے، جہاں سے اسے بعد میں مستقل طور پر ہٹا دیا جاتا ہے۔ ایپ اَن انسٹال کرنے سے اس کا تمام مقامی ڈیٹا ہٹ جاتا ہے۔
