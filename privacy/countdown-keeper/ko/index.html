Countdown Keeper 개인정보 처리방침

최종 업데이트: 2026년 9월

Countdown Keeper(이하 “앱”)는 Thiban Tech Solutions가 배포하는 모바일 앱입니다. 본 방침은 앱이 사용자의 정보를 어떻게 처리하는지 설명합니다. 우리는 사용자의 개인정보를 존중합니다. 앱은 로그인이 필요 없으며, 우리는 사용자의 개인정보를 수집·판매·공유하지 않습니다.

앱이 처리하는 정보

앱은 사용자가 만든 콘텐츠, 즉 이벤트 제목, 날짜와 시간, 메모, 색상, 이모지 또는 선택적으로 첨부한 사진, 그리고 앱 설정을 저장합니다. 이 정보는 사용자의 기기에 저장되며, 카운터와 알림을 표시하는 데에만 사용됩니다.

기기 권한

  • 알림 — 알림 기능을 켠 경우에만 이벤트 전에 알려 드리기 위해 사용됩니다.
  • 카메라 — 선택 사항으로, 이벤트에 첨부할 사진을 촬영할 수 있도록 합니다.
  • 사진 — 선택 사항으로, 이벤트용 사진을 선택하거나 이벤트 이미지를 갤러리에 저장할 수 있도록 합니다.
  • 생체 인식 / Face ID — 선택 사항으로, 앱 잠금을 켠 경우에만 앱 잠금 해제에 사용됩니다.
  • 재시작 후 실행(Android) — 기기를 재부팅한 후에도 예약된 알림이 유지되도록 합니다.

각 권한은 관련 기능을 사용할 때에만 요청됩니다.

데이터 저장

모든 이벤트와 설정은 사용자의 기기에 로컬로 저장됩니다. 앱은 이벤트를 JSON 파일로 내보내고 다시 가져올 수 있으며, 해당 파일을 어디에 저장할지, 그리고 누구와 공유할지(공유하는 경우) 여부는 사용자가 결정합니다.

데이터 공유

우리는 사용자의 데이터를 판매하거나 공유하지 않습니다. 앱에는 사용자 계정도, Countdown Keeper 서버도 없으며, 사용자가 입력한 어떤 내용도 우리에게 전송되지 않습니다.

제3자 서비스

앱은 분석, 광고 또는 오류 보고 서비스를 사용하지 않습니다. 앱이 보낼 수 있는 유일한 네트워크 요청은 표시용 서체가 처음 필요할 때 이를 다운로드하기 위한 Google Fonts 요청입니다. 일반적인 웹 요청과 마찬가지로 이 요청에는 기기의 IP 주소가 포함되지만, 개인정보나 앱 콘텐츠는 전송되지 않습니다. 그 외에는 앱이 완전히 오프라인으로 작동합니다.

데이터 보관

사용자의 데이터는 사용자가 삭제할 때까지 기기에 보관됩니다. 이벤트를 삭제하면 휴지통으로 이동되며, 이후 휴지통에서 영구적으로 삭제됩니다. 앱을 삭제하면 앱의 모든 로컬 데이터가 삭제됩니다.

아동의 개인정보

앱은 아동을 대상으로 하지 않으며, 아동의 정보를 고의로 수집하지 않습니다.

보안

사용자의 데이터는 기기 자체의 보안 기능과 앱 샌드박스로 보호됩니다. 선택 사항인 생체 인식 앱 잠금을 사용하여 보호 계층을 한 겹 더 추가할 수 있습니다.

사용자의 선택

사용자는 기기 설정에서 앱의 권한을 관리할 수 있으며, 언제든지 앱 내에서 데이터를 내보내거나 삭제할 수 있습니다.

본 방침의 변경

우리는 본 방침을 수시로 업데이트할 수 있습니다. 변경 사항은 새 날짜와 함께 이 페이지에 게시됩니다.
